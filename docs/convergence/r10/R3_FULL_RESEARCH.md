## AUDIT & FALSIFICATION OF PASS R2
> [!IMPORTANT]
> In accordance with the Anti-Sycophancy Invariant, Pass R3 challenges the narrow scope of Pass R2. Pass R2 proposed scheme-checking and timeouts, but completely failed to defend against multi-hop affiliate redirect poisoning, token renewal stampedes (Thundering Herd), and incognito browser storage exceptions.

### Hostile Falsification & Negative Vector Blind Spots in Pass R2:

- **[L01 FALSIFICATION]** (Multi-Hop Affiliate Redirect Hijacking):
  - *Deficit in R2*: Pass R2 required `https:` protocol checks on booking URLs, but assumed affiliate networks redirect directly to carriers.
  - *Hostile Negative Vector*: Affiliate networks (e.g. Travelpayouts, Aviasales) frequently route through multi-hop redirect chains (`c100.travelpayouts.com -> intermediate-tracking -> sub-agent`). If a compromised sub-agent injects malicious query params or routes to an unverified third-party ticket reseller, the user is exposed to predatory booking markups.
  - *Correction in R3*: In `src/domain/farely/providerRights.ts`, enforce a strict whitelist of verified final destination hostnames (`vietnamairlines.com`, `vietjetair.com`, `bambooairways.com`, `vietravelairlines.com`) and display an explicit destination badge in `src/app/pages/DealDetailPage.tsx`.

- **[L05 FALSIFICATION]** (OAuth2 Token Renewal Stampede / Thundering Herd):
  - *Deficit in R2*: Pass R2 wrapped Amadeus calls in `AbortSignal.timeout(8000)`, but ignored shared credential expiration.
  - *Hostile Negative Vector*: In `supabase/functions/_shared/amadeus-provider.ts`, when an OAuth access token expires after 1800s, 50 parallel crawl requests simultaneously detect an expired token and trigger 50 simultaneous token refresh POST requests. Amadeus rate limits the IP with HTTP 429, paralyzing the crawler pipeline.
  - *Correction in R3*: Implement a single-flight mutex / in-flight token promise cache in `supabase/functions/_shared/amadeus-provider.ts` ensuring exactly one token refresh occurs while pending callers await the shared resolution.

- **[L06 FALSIFICATION]** (Incognito Mode Storage SecurityError Crash):
  - *Deficit in R2*: Pass R2 mandated 14-day IndexedDB eviction, but assumed storage APIs are always accessible.
  - *Hostile Negative Vector*: In strict privacy modes (Safari Private Browsing, Firefox Strict Privacy), calling `window.indexedDB.open()` or `localStorage.setItem()` can synchronously throw a `SecurityError` or `QuotaExceededError`. If unhandled, this prevents the entire React application from mounting.
  - *Correction in R3*: Implement an in-memory fallback storage adapter in `src/domain/farely/pwaOfflineFreshness.ts` that gracefully absorbs storage exceptions without degrading application boot.
